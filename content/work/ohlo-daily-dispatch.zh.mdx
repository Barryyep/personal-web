## 概述

[OHLO](https://ohlo.app) 是我正在设计和开发的一个个人项目 —— 一款围绕一个简单想法打造的
"每日好奇心" App：**每天只发一条，而不是一条信息流**。每天早上，用户会收到一条精选、
带来源和日期的趣味知识，配一句简短的说明，解释为什么它值得关心。

## 为什么做这个

大多数"发现类"App 都在优化无尽下滑。OHLO 反其道而行：只挑一件事 —— 有来源、有日期、
真正有意思 —— 然后就停在那里。目标是让用户获得一条好信息流才能带来的那种"每日小小满足感"，
但不必付出无限刷屏的代价。

## 怎么运作

- **好奇心雷达** —— 一个简短的入门测验，用来建立用户的好奇心画像，从而个性化地挑选每日内容。
- **每天一条** —— 每天只有一条知识，配一句"为什么值得关心"，把内容和用户的生活联系起来。
- **始终有来源** —— 每一条内容都附带可见的来源和日期，内容是可核实的，而不只是听起来合理。
- **中英双语** —— App 和网站同时支持中文和英文。

## 我在做的部分

- **内容生成管线** —— 用 LLM 来搜集、核实、组织每日内容的文案，保证准确、有趣，且语气统一。
- **移动端 App** —— 用 React Native / Expo 搭建客户端，先做 Android（已有 APK），iOS 正在推进中。
- **个性化** —— 把测验答案转化为好奇心画像，用来影响每日内容的选择。

## 技术栈

React Native · Expo · LLM 内容管线
